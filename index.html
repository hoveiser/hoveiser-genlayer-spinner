Design Rationale

Neural Consensus visualizes GenLayer's core mechanism: decentralized AI validators reaching agreement. Eight nodes arranged in a circle, with a signature gradient pulse traveling node-to-node, represent consensus being formed across the network.

Primary vs Alternative

  • Primary (Abstract): Ideal for small sizes (16-32px) where the animation alone conveys the brand identity through motion and gradient
  • Alternative (With Mark): Best for larger contexts (32px+) where the official GenLayer mark should be clearly visible alongside the loading state

Technical Specifications

  • Pure SVG + CSS animations — no JavaScript, no dependencies
  • File size: ~1.5KB per variant
  • Seamless infinite loop (1.6s cycle, within GenLayer's 1.5-3s motion guidelines)
  • Works on both light (#F5F5F5) and dark (#070707) backgrounds
  • Crisp and readable from 16px to 96px
  • Accessibility: includes role="img", aria-label, and respects prefers-reduced-motion

Brand Compliance

Built against the official GenLayer Design System (genlayer-foundation/genlayer-design):

  • Signature gradient #E37DF7 → #9B6AF6 → #110FFF (the brand's primary motif) drives the active pulse
  • Idle nodes use neutral ink #6B6B6B; single accent #110FFF
  • Motion: 1.6s gentle ease loop — inside the brand's 1.5–3s window; no bounce/spring
  • The official mark (GenLayer_Mark_White.svg) is used unmodified and never rotated, on a gradient tinted container — the brand's own small-icon pattern
